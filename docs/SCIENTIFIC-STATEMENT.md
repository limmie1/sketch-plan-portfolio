# 科学性先进性说明：Sketch Plan

## 一、所依据的科学原理

习惯形成依赖低摩擦的重复：Lally 等跟踪 96 名被试 12 周，发现自动化沿渐近曲线上升，达平台期中位 66 天，偶有遗漏不显著影响进程[1]。故制约成效的关键变量是单次记录成本，而非功能数量。技术上，日程录入本质是时间表达式的识别与归一化，规则驱动的确定性解析可稳定达到较高准确率[2]；多视图是同一数据的投影，单一事实源可消除派生状态的口径漂移。

## 二、技术方案的合理性与创新

（1）逐段消解加已消费片段记录，实现中文时空归一化，可复现、可离线，不依赖模型推理。（2）事件按系列与实例分离建模，重复规则仅生成实例，例外修改不污染整组。（3）数据、组件、皮肤三层解耦，换肤仅替换令牌，不复制组件。（4）本地先改、失败回滚，网络往返不阻塞交互，失败可恢复一致[3]。

## 三、与现有方法的对比

相较表单式日历，录入由六步降至两步；相较派生视图各自维护的实现，单一事实源消除同步延迟与口径不一致；相较纯云端方案，可离线与自托管，契合本地优先原则[3]。
