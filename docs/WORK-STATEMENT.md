# 作品说明：Sketch Plan

## 一、设计与发明目的

现有工具录入需新建、选日期、时刻、时长与分类，成本高；多视图数据各自维护，口径易漂移；复盘依赖导出表格。本作品以降低录入成本、统一数据源、内建复盘为目标。

## 二、基本思路与实现框架

以事件为单一事实源，分数据、组件、皮肤三层，各负责读写迁移、尺寸约束、令牌替换。前端用原生 JavaScript，服务端用 Node 与 SQLite，桌面与手机自适应。写入采用本地先改、再提交、失败回滚。录入以规则解析短句，预览后写入。

## 三、创新点

1. **中文速记**：一句话生成含日期、时刻、时长、重复与提醒的事件，交互由六步降至两步。
2. **单一事实源**：八个视图共享数据，较分散存储消除同步延迟与口径不一致。
3. **令牌化皮肤**：仅换色彩、描边、圆角、字体令牌，8px 网格约束尺寸，切换无布局位移；较逐主题复制组件，实现量下降。
4. **乐观更新**：本地先改再提交，失败回滚重拉，较等待服务端返回消除操作等待。

## 四、关键技术与难点

中文时空解析为首要难点：相对与绝对日期、口语时刻、时长与提醒混排，须判定残留文本；以逐段匹配与已消费片段防重复。回滚一致性次之：写失败须区分本地态与服务端态，避免部分成功。令牌须覆盖全部视觉属性，否则布局抖动。

## 五、主要技术指标

八视图三主题、十张数据表；脚本合计 206KB；拉取前后 45 至 75 天；提醒扫描 30s；备份保留 14 份（部署核对）；解析 5 类时空要素、4 类重复规则；快捷键 11 个；动效 700+60+220ms，减动效 240ms（帧采样）；JSON 导出（功能核对）。
