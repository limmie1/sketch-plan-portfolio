# Sketch Plan · 微信小程序端

原生小程序工程，与网页版**功能对齐、视觉一致、数据独立**。
不依赖 web-view、不依赖备案域名：页面是原生 WXML/WXSS，数据存在本机 `wx.storage`。

---

## 1. 快速开始

### 1.1 导入

1. 打开微信开发者工具 → **导入项目**
2. 目录选到本文件夹（`sketch-plan/miniprogram`，注意不是仓库根目录）
3. 本地预览使用工程配置中的游客 AppID。正式发布时，在开发者工具中填入自己的小程序 AppID
4. 点「导入」→ 模拟器直接出「今天」页

### 1.2 登录（微信官方链路）

本项目**不自建账号体系**，只用微信官方身份能力：

```
小程序端                     云函数 login               微信服务
wx.login()      ──────►  cloud.getWXContext()
  拿到 code       ──────►    返回 OPENID      ◄──────  微信颁发
        │                          │
        └──── callFunction ────────┘
                   │
             本机缓存登录态（openid / 昵称 / 头像）
```

- 头像昵称用官方现行组件：`button open-type="chooseAvatar"` + `input type="nickname"`，不再弹 `wx.getUserInfo` 授权框
- **启用云开发**：微信开发者工具 → 云开发 → 开通环境 → 把环境 ID 填进 `config.js` 的 `CLOUD_ENV`
- **部署云函数**：右键 `cloudfunctions/login` → 上传并部署（云端安装依赖）
- 没配 `CLOUD_ENV` 时进入「本机模式」：仍然能用，只是没有 OPENID，界面上会写明

> 为什么不用「自建服务端 code2session」：那要求 `request` 合法域名，域名要备案。本项目服务器在境外，备案走不通；云开发不需要域名也不需要备案，是个人主体最顺的官方路径。

### 1.3 数据

- 全部落在 `wx.storage`，key 为 `sketchplan.mp.v2`
- 与网页版**完全不相通**：网页版写 `localStorage`（`sketchplan.v1::*`），两端各存各的，不做同步
- 首次启动写入一份示例数据（相对当天生成），可在「我的 → 设置 → 数据」里清空或重载
- 卸载小程序 / 清缓存 → 数据一起消失，这一点在「关于」页有明示

## 3. 与网页版的功能对照

| 网页版视图 | 小程序 | 说明 |
|---|---|---|
| 月历 `month` | `pages/calendar` | 6×7 网格、今天/选中、有日程画点 |
| 周表 `week` | — | 手机屏宽放不下 7 列时间轴；用「时间轴 + 日历」两页替代 |
| 时间轴 `timeline` | `pages/timeline` | 06:00–24:00 刻度、事件块按时间落位、当前时刻红线 |
| 进度 `progress` | `pages/progress` | 长期目标 +1 打卡；长期计划只读展示 |
| 工作集 `collections` | `pages/collections` | 卡片 + 进度条 + 展开看日程 |
| 分类 `cats` | `pages/cats` | 增/改/删，删除前先迁移内容 |
| 复盘 `review` | `pages/review` | 周维度完成率、每日柱、分类时长、三问三答 |
| 我的 `me` | `pages/mine` | 统计卡 + 工具入口 + 换肤 |
| 便签 `note` | `pages/note` | 整页便签，边写边存 |
| 速记 `capture` | `pages/capture` | 同一套中文解析规则，本地跑 |
| 搜索 `/` | `pages/search` | 标题/备注/分类/工作集/计划 |
| 批量排课 `openBatch` | — | 折损为「速记里写重复」：`每天早上七点半 背单词 30分钟` |
| 左右双栏 + 右栏详情 `insp` | — | 手机是单栏；详情进各页内联或弹层 |

## 4. 无法 1:1 对应的地方，与最接近的替代

| 网页版能力 | 小程序限制 | 替代实现 |
|---|---|---|
| `localStorage` 多账号数据隔离 | 没有浏览器域隔离，数据属于「这台设备」 | 数据按设备存；登录只认人，不切数据。多账号诉求建议后续接云数据库按 `openid` 分库 |
| `Notification` / 站内提醒弹窗 | 小程序不能后台弹通知 | 保留 `remind` 字段；要真提醒需接**订阅消息**（一次性授权，每发一条要用户点一次授权），未做 |
| 键盘快捷键（M/W/G/P/C/L/R/B、`/` 搜索） | 无物理键盘 | 全部改成页面入口（tab + 我的 → 工具） |
| 桌面端双栏、右栏"当日安排" | 单栏布局 | 月历页下方直接列当日清单；时间轴页承担"看时间分布" |
| 拖拽调整事件块 | 拖拽体验差、易误触 | 时间轴长按 → 推迟一天 / 改标题 / 删除 |
| 批量选择、批量改期 | 无多选交互 | 整组重复日程可一次性删除（`seriesId`） |
| 导出 / 导入 JSON、打印 | 无文件系统直写 | 未做；数据在 `wx.storage`，可后续加"复制为文本" |
| 跨端同步（网页 ↔ 小程序） | 需求已明确不需要 | 两端独立存储，互不读写 |
| 邮箱登录（网页版旧机制） | — | 小程序端不移植，改为微信官方登录 |

## 5. 自检脚本

仓库根目录下：

```bash
node .mpcheck.cjs
```

会检查：13 个页面四件套齐全、62 个事件绑定的处理函数都存在、14 个 WXML 标签配平、15 个 WXSS 花括号配平，并打桩 `wx.*` 后跑一遍数据层（增删改查、分类迁移、重复日程、计划进度、复盘统计、便签、搜索、速记解析）。当前结果：**全部通过**。
